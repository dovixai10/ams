Sending method A of 2. This is the official Business API. It works on its own — you do not need a Linked Phone (QR). Use either one, or both.
How to connect a number (Meta WhatsApp Cloud API)
  1. In Meta Business Suite / developers.facebook.com, open your app → WhatsApp → API Setup and copy the Phone number ID.
  2. Create a System User with the whatsapp_business_messaging permission and generate a permanent access token.
  3. Save both here, then use Send test on a recipient to confirm it works.
A branch uses its own account if it has one, otherwise the whole-office account.
{% elif kind == 'sessions' %}
Sending method B of 2. A linked phone works on its own — you do not need a Business API account. Use either one, or both.
Send from a phone you already use — no Meta account needed.
  1. Add the phone here, then press Link phone on its row.
  2. On that phone open WhatsApp → Linked devices → Link a device and scan the QR code.
  3. Once it says Connected, choose Via linked phone (QR) on a Report Schedule. Reports can go to any number, or to any group that phone is in, by the group's name.
This uses WhatsApp's linked-device feature the way WhatsApp Web does, but it is not an official WhatsApp API: WhatsApp can restrict a number that sends automated messages, so use it for a few internal recipients, not bulk messaging. The whatsapp_web helper (node server.mjs) must be running.
{% elif kind == 'recipients' %}
One entry can hold many numbers and many groups — e.g. an "HR team" entry with two managers' numbers and the HR group. Separate several items with commas, and pick that one entry on a Report Schedule to reach all of them.
  • Phone numbers — country code, digits only (e.g. 919876543210). Works with both sending methods.
  • Group names — for the linked phone (QR) method: names exactly as on that phone (the Linked Phone page lists them for copying).
  • Group IDs — for the Business API method. Press Create WhatsApp group to make one and get its ID and invite link, or Sync groups from Meta to import existing ones. Meta only enables the Groups API for eligible (Official Business Account) numbers.
Fill in whichever fit the method(s) you use; a schedule only uses the ones for its own method.
